# Courtside walkthrough

A narrated video explaining the frontend refinement and the mobile layout.

- `courtside-walkthrough.mp4` — 1920×1080 H.264 video with AAC audio and visible English captions.
- `courtside-walkthrough-voiceover.mp4` — the same walkthrough with louder English narration, normalized to approximately -16 LUFS, and the audio track selected by default.
- `courtside-voiceover.mp3` — the normalized narration as a standalone audio file.
- `captions.srt` — separate caption file.
- `transcript.txt` — narration grouped by chapter.
- `poster.jpg` — video preview.

The seven chapters cover the desktop workspace, phone library, Live Court setup,
shot reports, progress charts, upload dialogs, and portrait/landscape navigation.
The app screenshots show illustrative sample sessions, not measured live play.

Narration uses the installed Microsoft Zira Desktop voice. The connected speech
service was unavailable, so no external audio generation was used in the final
video. `narrate.ps1`, `render.py`, the screenshots, and the timing data are retained
to make the walkthrough editable.
